## Plan Tree Long-Term Project Management

Use the installed `plan-tree` skill as the planning authority for roadmap work, requirement clarification, scope or implementation strategy, execution-readiness checks, progress tracking, handoff, decisions, open questions, and plan-to-landing evidence.

Before direction-changing implementation, inspect `docs/plantree/README.md` and the relevant current Plan when they exist. If durable planning state is needed but absent, use the skill to create only the minimal Plan Tree structure.

Keep implementation and planning state synchronized: resolve core ambiguity before formal implementation, then update roadmap, status, decisions, questions, and evidence after work lands.

Plan Tree governs planning state; it does not grant permission for commits, pushes, releases, destructive actions, or unrelated scope expansion.
